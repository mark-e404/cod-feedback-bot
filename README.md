# Telegram-бот: обратная связь, опросы и викторины

Бот принимает от пользователей вопросы и предложения, пересылает их администраторам и возвращает ответы автору. Администраторы также могут делать опросы, голосования и викторины, рассылать анонсы, банить спамеров и обновлять бота прямо из Telegram.

Написан на Python, [aiogram 3](https://docs.aiogram.dev/), хранит данные в SQLite.

---

## Возможности

### Для пользователей

- **Подтверждение, что вы не бот.** При первом `/start` нужно решить простой пример нажатием кнопки.
- **Меню из кнопок.** Набор кнопок настраивают админы. По умолчанию есть «Задать вопрос» и «Предложить идею».
- **Вопрос.** Пользователь пишет текст, админы получают его и отвечают, ответ приходит в тот же чат вместе с цитатой вопроса.
- **Предложение.** Работает так же, но отвечать админам необязательно.
- **Опрос, голосование, викторина.** Нажатие на такой пункт меню присылает готовый опрос. Повторно пройти его нельзя.
- **Анонсы.** Рассылки от админов приходят в личные сообщения (текст, фото, видео, файлы, голосовые, а также опросы и викторины).
- **Кнопка Menu** слева от поля ввода со списком команд.

| Команда | Что делает |
|---|---|
| `/start` | Запуск бота, проверка «я не бот», показ меню (у админа — панель) |
| `/menu` | Главное меню (у админа — панель) |
| `/id` | Показывает ваш Telegram ID (нужен для настройки админов) |

### Типы пунктов меню

| Тип | Что получает пользователь |
|---|---|
| Вопрос | Подсказку и поле для текста; админ должен ответить |
| Предложение | Подсказку и поле для текста; ответ по желанию |
| Опрос | Telegram-опрос, можно выбрать **несколько** вариантов |
| Голосование | Telegram-опрос, можно выбрать **один** вариант |
| Викторина | Telegram-викторина: один верный ответ и необязательное пояснение |

### Антиспам

Применяется к вопросам и предложениям. Значения по умолчанию (супер-админ меняет их из панели без перезапуска):

- пауза между сообщениями — 60 секунд;
- не больше 3 сообщений в час и 10 в сутки;
- длина текста от 8 до 2000 символов;
- не больше 2 ссылок и @упоминаний в сообщении;
- отсеиваются «мусорные» тексты вроде `аааааа` и точные повторы уже отправленного.

### Панель администратора

Открывается командой `/start` или `/menu` у админа.

- **Статистика.** Число пользователей, активных за 24 часа, заблокировавших бота, вопросов (сколько отвечено), предложений и опросов. Есть списки активных и забаненных пользователей с постраничной навигацией.
- **Пункты меню.** Добавление, удаление и просмотр кнопок меню пользователей (до 12 пунктов, название до 40 символов). Тип пункта выбирается из пяти вариантов. Для вопроса и предложения задаётся подсказка, для опроса, голосования и викторины — вопрос и варианты.
- **Анонс пользователям.** Можно отправить любое сообщение (бот скопирует его всем подтверждённым, не забаненным и не заблокировавшим бота) либо создать опрос, голосование или викторину. Перед отправкой показывается число получателей. По окончании рассылки админ получает отчёт.
- **Опросы и викторины.** Список последних 10, а для каждого — сколько человек получили опрос, сколько ответили, голоса и проценты по вариантам. Для викторины ещё и сколько ответили верно.
- **Модерация.** Бан и разбан по ID или @username (только тех, кто уже писал боту). Под каждым обращением есть кнопка «Забанить автора».
- **Ответы пользователям.** Нужно нажать «Ответить» (Reply) на сообщении с обращением. Ответ может быть текстом, фото, голосовым или файлом. Остальные админы получают копию ответа.

### Роли

| Роль | Откуда берётся | Что может |
|---|---|---|
| Админ | `ADMIN_IDS` в `.env` или добавлен супер-админом | Ответы, статистика, меню, анонсы, опросы, модерация |
| Супер-админ | `SUPER_ADMIN_IDS` в `.env` или повышен другим супер-админом | Всё перечисленное, а также: лимиты антиспама, управление админами, обновление бота |

Роли из `.env` «корневые»: из панели их изменить нельзя. Остальных админов супер-админы добавляют, повышают, понижают и удаляют кнопками. Администраторы не участвуют в пользовательских сценариях (для них бот показывает панель).

### Обновление из GitHub

Супер-админ в панели: **Обновление бота → Проверить обновления → Установить и перезапустить**. Бот сам выполняет `git pull --ff-only`, при необходимости ставит новые зависимости и проверяет, что код компилируется, иначе откатывает изменения. После перезапуска он пишет, с какой версии на какую обновился. Для этого бот должен быть запущен из клона репозитория.

## Установка

Нужны Python 3.10+ и Git. Токен бота выдаёт [@BotFather](https://t.me/BotFather), свой ID можно узнать у бота командой `/id` (или у любого бота, который его показывает).

```bash
git clone git@github.com:ВАШ_ЛОГИН/ИМЯ_РЕПО.git
cd ИМЯ_РЕПО
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
chmod 600 .env
nano .env                  # впишите BOT_TOKEN и ID админов
python bot.py
```

Каждый администратор должен хотя бы раз открыть бота и нажать **Start**, иначе бот не сможет ему написать. При запуске бот проверяет это и пишет в лог, кого не смог достать.

Полные списки команд по выкладке на GitHub, развёртыванию на сервер, обновлению и откату — в [DEPLOY.md](DEPLOY.md).

### Настройки `.env`

| Переменная | Обязательно | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен от @BotFather |
| `ADMIN_IDS` | нужна хотя бы одна из двух | ID админов через запятую |
| `SUPER_ADMIN_IDS` | нужна хотя бы одна из двух | ID супер-админов через запятую |
| `DB_PATH` | нет | Путь к базе SQLite (по умолчанию `bot.db` рядом с ботом) |
| `PROXY_URL` | нет | Прокси для доступа к Telegram, например `socks5://127.0.0.1:1080` |
| `IPV4_ONLY` | нет | Любое значение, например `1`: использовать только IPv4 (если сломан IPv6) |

Старая переменная `OWNER_ID` читается как `ADMIN_IDS`.

### Запуск как сервис (Linux, systemd)

```bash
sudo bash deploy/install-service.sh
```

Скрипт ставит зависимости, создаёт сервис с автозапуском и перезапуском при падении. Подробности в [DEPLOY.md](DEPLOY.md).

## Данные и резервные копии

Всё хранится в одном файле SQLite (`bot.db`): пользователи, обращения, пункты меню, админы, лимиты, опросы и ответы на них. Файл не попадает в Git. Для копии достаточно:

```bash
cp bot.db bot-$(date +%F).db
```

## Ограничения и особенности

- **Опросы неанонимные.** Иначе Telegram не сообщает боту, кто что выбрал, и результаты нельзя было бы подсчитать. Участники видят, что опрос неанонимный.
- **Лимиты Telegram:** вопрос опроса до 300 символов, до 10 вариантов по 100 символов, пояснение викторины до 200 символов.
- **Незавершённые формы** (например, админ посреди создания опроса) хранятся в памяти и сбрасываются при перезапуске бота. Сохранённые данные и результаты опросов при этом не теряются.
- **Альбомы** (несколько фото одним сообщением) в анонсах не поддерживаются.
- **Опрос из пункта меню** можно пройти один раз. Если человек отозвал голос, результат не учитывается и пройти опрос снова можно.
- **Не правьте файлы на сервере вручную:** обновление выполняется как `git pull --ff-only` и откажется работать при расхождении с репозиторием.
